这本册子怎么来的

题目要求做一个不少于五页的个人网页，主题自定，页面之间用相对路径互相链接。我选了家乡天水：一来素材近，二来它确实值得写——一座城同时拥有石窟、庙宇、古城和一套自己的早饭，这样的地方不多。

全站六个页面：卷首（首页）、麦积山、伏羲庙、古城名刹、天水食味、关于本站。首页负责把五章串起来，每一章的页眉与页脚都能回到任意一章，任何时候都不会走进死路。

技术上没有用任何框架，也没有引入第三方 JS。所有页面共用一份 CSS 与一份 JS，图片全部下载到本地 images/ 目录，链接一律写成 maijishan.html 这样的相对路径，因此整个文件夹拷到任意目录、任意域名下都能直接打开。

用到的工具

编辑器 VS Code；浏览器 Chrome 做预览与响应式调试；图片统一压缩到长边 1600 像素再入库，避免仓库里堆着几 MB 的原图；版本管理用 Git，最后通过 GitHub Pages 发布。排版上没有用图标字体，全站的字形、印章、时间轴与中轴线图都由 CSS 和元素本身画出来。

图片与文字

照片来自公开报道与图库检索页（人民网、新华社、视觉中国、图虫创意、中新网等），仅用于课程作业演示，不作商业用途，版权归原作者所有。若需替换，把新的同名文件放进 images/ 目录即可，页面不需要改动。

文字为本人撰写，数据均来自政府与文物部门的公开页面，出处列在下方。个别民间传说（如呱呱与隗嚣之母的掌故）在正文里已写明「相传」，与史实记载区分开。

制作过程

四步做完

  • 一定选题与结构：确定六页的章次、每页要讲的事，画一张页面关系草图。
  • 二找素材：逐张核对图片内容与地点，确认清晰、无水印，压缩后入库。
  • 三写页面：先写共用 CSS 与 JS，再从首页往分页面推进，每页都做宽屏与窄屏两次预览。
  • 四自检与发布：逐页点一遍所有链接，检查相对路径，最后推送 GitHub 并开启 Pages。
